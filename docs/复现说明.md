# B 榜最优结果复现说明（四级复现链）

**目标成绩**：B 榜 1.1803393647383136（dataset3 + dataset4 直接相加）
**终稿真身**：`final_submission/dataset3.csv.gz`、`dataset4.csv.gz`
（解压后 md5 应分别为 b1828cda9f71e79c28e77e33be564999 /
80694df1f404908946194429627e0584）

复现分四级，逐级代价递增；**L1/L2 为确定性计算，纯 CPU 即可完成**。

---

## L1：终稿文件对照（秒级）

```bash
cd final_submission
gzip -d -k dataset3.csv.gz && gzip -d -k dataset4.csv.gz
md5sum dataset3.csv dataset4.csv   # 与上方两个 md5 对照
```

## L2：融合层复现（分钟级，CPU，已验证逐字节一致）

**本包已自带全部 8 个输入秩矩阵**（`rank_matrices/` 目录），无需任何 GPU 推理即可复现终稿：

```bash
cd code/fusion
bash repro_p33.sh ../../rank_matrices
# 脚本结尾自动做 md5 自校验，输出两个 OK 即与线上提交逐字节一致
```

输入为 8 个秩矩阵文件（rank-percentile 空间，形状 = 测试行数 × 100）。
ds4 侧的内层六成员融合（v3 0.15 + honest 0.15 + rolloutA 0.15 + rolloutB 0.15
+ craft_e15 0.30 + heur2 0.10）已预先由同一套 emit_nway.py 合成为
p5mix_h_rank.npy；**v3 成员的 ckpt 虽已灭失，其推理产物已包含在该文件内，
本层复现不受影响**。各成员原始秩矩阵由 L3 推理产物经 `code/fusion/rank_prep.py`
转换而来（确定性序号秩：行内稳定排序，同分按候选列序，rank/100）。

融合配方（终稿精确权重）：

```
dataset3.csv = 0.17*(s1+s2+s3+s4+s5) + 0.15*h384
dataset4.csv = 0.70 * p5mix_h + 0.30 * tm4
```

## L3：推理层复现（GPU，ckpt → 各成员输出）

环境：Python 3.9/3.10 + Jittor 1.3.8.5（CUDA 11.2/11.8 验证通过）+ requirements.txt。
工作目录须纯 ASCII。数据准备：官方 `dataset3/`、`dataset4/`（train.csv + test.csv）
放入工作目录，特征预计算命令见 L4 第 0 步（或由训练流程自动生成）。

### L3-ds4（dataset4_graphmixer）

```bash
cd code/dataset4_graphmixer
# v4a / v4b / honest 冻结推理（训练脚本在训练结束自动完成；
# 亦可单独执行：）
python code/rollout_predict_d4.py --mode frozen --dataset dataset4 --data_dir . \
  --checkpoint ../../ckpt/dataset4/saved_gm_d4_v4a/dataset4_graphmixer.pkl --out v4a.csv
python code/rollout_predict_d4.py --mode frozen --dataset dataset4 --data_dir . \
  --checkpoint ../../ckpt/dataset4/saved_gm_d4_honest/dataset4_graphmixer.pkl --out honest.csv
# rolloutA / rolloutB（推理期 top1 自注入，B 榜关键增量）
python code/rollout_predict_d4.py --mode rollout --gate_margin 0.0 --dataset dataset4 \
  --data_dir . --checkpoint ../../ckpt/dataset4/saved_gm_d4_v4a/dataset4_graphmixer.pkl --out rolloutA.csv
python code/rollout_predict_d4.py --mode rollout --gate_margin 0.0 --dataset dataset4 \
  --data_dir . --checkpoint ../../ckpt/dataset4/saved_gm_d4_v4b/dataset4_graphmixer.pkl --out rolloutB.csv
# craft_e15 / heur2（纯启发式，无 ckpt）
python craft/craft_ds4_train.py && python craft/craft_ds4_score.py   # 产出 craft_e15 分数
python code/heuristic_scorer_d4.py                                   # 产出 heur2 分数
# 之后统一转秩：
python ../fusion/rank_prep.py --src <成员csv> --out <成员rank.npy>
```

### L3-ds3（dataset3_graphmixer）

ds3 各成员的测试推理由训练脚本在训练结束时自动完成（加载验证集 MRR 最优 ckpt →
100 候选打分 → rank_percentiles 写出 `saved_cf_s<S>/dataset3.csv`）。对已提交 ckpt
做核验时，将训练命令（见 L4-ds3）加 `--init_checkpoint <ckpt路径>` 并复跑即可
重新走训练/推理流程；或直接以 L4 命令重训（单种子 RTX 4090 约 2~3 小时）。

### L3-tm4（dataset4_temporal_ranker，队友系统）

见 `code/dataset4_temporal_ranker/` 内说明；参考入口 `run_remote_dataset4.sh`

## L4：训练层复现（train.csv → ckpt，GPU，单成员数小时~十几小时）

第 0 步特征预计算（ds4；ds3 类似，脚本在 dataset3_graphmixer/ 内）：

```bash
python code/gen_features_ds4.py            # 双路 Node2Vec 256 维 + idmap_ds4.npz
python code/precompute_heuristics.py --dataset dataset4 --data_dir .
python code/build_cooc_ds4.py              # 近似共现表 cooc_ds4.npz
python code/build_hardnbr_ds4.py           # 硬负例表 hardnbr_ds4.npy
```

训练命令（与线上产物一一对应）：

| ckpt | 命令 |
|---|---|
| ds3 saved_cf_s1~s5 | `cd code/dataset3_graphmixer && bash train_d3_seeds.sh`（s1~s3）与 `bash train_d3_more.sh`（s4/s5） |
| ds3 saved_cf_h384 | `bash train_d3_more.sh` 内 H384H100 段（hidden384/hist100/seed 11） |
| ds4 v4a | `cd code/dataset4_graphmixer && bash train_v4a.sh` |
| ds4 v4b | `bash train_v4b.sh` |
| ds4 honest | `bash train_honest.sh` |
| ds4 v3（已灭失，复训用） | `bash train_v3s45.sh`，将 `--seed 45` 改 `43`、`--save_dir` 改 `./saved_gm_d4_v3` |

注：训练存在 ±0.002 MRR 级固有波动；多种子秩融合正是为抑制该波动而设计。
